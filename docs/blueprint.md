# Blueprint - al-shehapi

هذا الملف يوضح مخطط البناء الكامل من الصفر لنظام **shehapi honey** مع الحفاظ على قواعدك المالية.

## المجلدات
- honey_system/: إعدادات المشروع.
- core/: التطبيق الأساسي (نماذج، منطق، قوالب).
- core/templates/core/: واجهات RTL.
- core/templatetags/: فلاتر واجهة.
- docs/: وثائق البناء والتشغيل.

## النواة المنفذة حاليًا
- نماذج بيانات أساسية لكل الوحدات (موظفين، مخزون، بيع، حسابات، موردين، رأس المال، مصارفة، عروض).
- SaleItem.inventory قابل لأن يكون null لحفظ تاريخ البيع بعد حذف المخزون.
- دوال البداية:
  - log_system_change
  - refresh_financial_balances (TODO)
